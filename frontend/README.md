# BANTADS - Frontend

Frontend do **BANTADS**, desenvolvido em Angular para o projeto da disciplina de Desenvolvimento de Aplicações Corporativas.

## Tecnologias

- Angular 22
- TypeScript
- Angular Material
- Decimal.js
- Luxon

## Requisitos

- Node.js 24.15.0 ou versão compatível
- npm

Caso utilize NVM:

```bash
nvm use 24.15.0
```

## Instalação

Dentro da pasta `frontend`:

```bash
npm install
```

## Executar

```bash
npm start
```

A aplicação ficará disponível em:

```text
http://localhost:4200
```

## Build

```bash
npm run build
```

O build será gerado em:

```text
dist/banTADS
```

## UI

O projeto utiliza **Angular Material** como UI Kit.
